# PR Report: Submission artwork quality and formatting

PR: [#4132](https://github.com/6529-Collections/6529seize-frontend/pull/4132)
Branch: `agent-prxt/drop-media-formatting` -> `main`

The Memes submission artwork view now renders supported first-party still images through the existing responsive Next image optimizer, using the original upload and quality 100 instead of a previously downscaled CDN image.

- Images and GIFs have an always-visible HD control in the artwork view and popup, with the selected mode shared between both views. HD is the leftmost action in both toolbars. Original-load failures restore the preview and allow an accessible retry.
- Description text preserves authored line breaks, blank lines, and spaces.
- GIF default previews, feeds, DMs, supplemental images, and other media retain their existing behavior. Product documentation and the Help Bot index describe the new controls.

This is frontend-only and requires no backend, API, configuration, or dependency changes. Higher-quality previews increase transfer size and server-side processing, using the optimizer's existing cache. Quality 100 is an encoder setting rather than a lossless guarantee. Next may pass through source bytes for other animated raster formats or images it cannot re-encode; failed preview requests retain the existing scaled fallback.

Browser execution and visual verification remain a follow-up because this task excludes opening a browser or starting a local server. The separately reported DM image-quality issue is outside this change's requested scope.

The new controls follow the application's existing progressive localization: untranslated locale messages fall back to the complete English source dictionary.
