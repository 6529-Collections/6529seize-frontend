# PR Report: Museum snapshot Git ref resolution

Related PRs: None

## Summary

Museum snapshot generation resolves the public repository's main branch through Git instead of GitHub's anonymous REST API, avoiding quota-related `publication_github_http_403` build failures.

## What Changed

- Accept one exact `refs/heads/main` record containing a full lowercase commit SHA, then pin `GitHubMuseumPublicationSource` to that SHA for all publication-load attempts.
- Limit Git to three attempts, 30 seconds per attempt, 4 KiB output, and capped retry delays. Disable credential helpers, terminal prompts and askpass programs for the public lookup.
- Preserve catalog, manifest, assembly bundle and document hash verification, fail-closed behavior, and atomic snapshot replacement.
- Add regression coverage for invalid/ambiguous refs, command failures, execution bounds, exact-SHA pinning, and rejected content.
- Type the regression mock against Node's actual promisified Git command API.
- Adapt Core commit `dc191868c7a8c59c752f2999e20ab6fd76def67e` without modifying Core.

## Frontend Impact

The build-time publication snapshot changes only its initial main-ref lookup. Museum routes, content, browser interactions and generated API models are unchanged.

## Config / Env

Git and HTTPS access to GitHub's Git endpoint are required at build time; no token or new configured environment variable is needed. Git is already a documented prerequisite. PR CI, staging, reusable production artifact builds and runner benchmarking execute required Git commands in the same job before building. Those build jobs have no container override, including when a custom runner is selected. The separate Playwright container does not execute this snapshot step. No build-image change is necessary.

The snapshot command supplies its own non-interactive child-process environment. Git or content verification failures stop snapshot generation; there is no unverified fallback.

## Release Notes

Frontend builds no longer consume the anonymous GitHub REST quota to resolve Museum main. Publication authenticity and content integrity checks remain in force.
