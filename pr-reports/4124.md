# Supplemental drop media actions

PR: https://github.com/6529-Collections/6529seize-frontend/pull/4124
Branch: `agent-prxt/drop-additional-media-actions` → `main`

## Summary

Preview and supporting images in Memes drop details open the shared zoomable
viewer, with download, open-original, and supported fullscreen actions.
Promo and supporting videos expose original-file actions through the existing
player; MOV files offer download without direct browser opening.

## What Changed

- Reuse shared interactive image rendering inside the existing centered frames.
- Preserve the four-item supporting-media limit and video preload behavior.
- Keep distinct image descriptions and open buttons for preview/supporting images.
- Section headings and supplemental image labels use message keys; locales without
  translations fall back to English through the shared message helper.
- Update the user guide and Help Bot's media-viewer guidance.
- No backend, API, configuration, or dependency changes.

## Risks / Follow-Ups

Browser rendering and interaction checks were not executed because this task
excludes browser use. Supplemental image overlay coverage was added to the
existing composer sandbox for later desktop/mobile execution.

Supplemental section labels and the video save dialog currently fall back to
English for untranslated locales. Future translation work should populate the
`drop.additionalInfo.*` keys; viewer action translations remain owned by the
shared media components.
