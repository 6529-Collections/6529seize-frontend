# Active votes and wave sidebar navigation

[PR #4122](https://github.com/6529-Collections/6529seize-frontend/pull/4122) makes active TDH voting discoverable and removes the need to scroll through pinned waves before reaching other collections.

Active Votes and Worth Checking Out share a collapsible discovery section. The active count stays visible, named previews show voting deadlines or next decisions, and the view-all links open the matching discovery view. Pinned, Joined and All become peer controls above one wave list; signed-out visitors see All Waves.

Inline wave search spans accessible non-DM waves independently of the selected collection. It shows creator and pinned/joined status, supports pagination, retains the query when opening a result and restores the collection on clearing. Existing name matching remains unchanged; approximate search and relevance ranking are outside this PR.

The redesign retains announcements, unread/pin controls, subwave navigation, recommendation score links and DM behavior. Discovery preferences, collection selection and viewer-specific search queries survive navigation. Collection scroll restoration is owned by sidebar navigation, so virtual-list resets do not compete with tab switches.

Deploy the API from [backend PR #2126](https://github.com/6529-Collections/6529seize-backend/pull/2126) first. Visibility of an active vote does not guarantee voting eligibility. New UI messages use the existing English locale fallback.

Browser coverage was updated for the new discovery and search flow, but runtime layout, scroll and keyboard verification remains outstanding because no local server was authorized and the feature has not been deployed. No deployment is included in this handoff.
