# Sidebar and account menu stability

PR: [#4061](https://github.com/6529-Collections/6529seize-frontend/pull/4061)

## Summary

Keep sidebar utilities and the account control stationary as wallet restoration,
profile images, notifications, and Update availability resolve. Prevent the
artwork documentation item from appearing late inside an already-open account
menu. Existing server rendering and public SEO content remain intact.

## Changes

- Separate scrollable primary navigation, Search/Share, and bottom account
  actions. Conditional Drop Forge and Watchtower stay in the navigation section.
- Anchor the account control at the bottom, Notifications immediately above it,
  and optional Update above Notifications or directly above the signed-out icon.
  No empty notifications row appears for signed-out visitors.
- Use a fixed 40px shimmer, avatar, or default icon. Missing, broken, and stalled
  images fall back to the icon; failed profile requests expose a retry action.
  An empty successful result links to profile setup. Screen readers receive
  account identity and retry feedback. A timed-out avatar stays on its fallback
  until the account or image URL changes, avoiding another delayed image swap.
- Keep artwork access subscribed while the account UI is mounted. Opening the
  menu captures its current availability; late positive results appear next
  opening, while revoked access disappears immediately. Account/proxy changes
  are isolated and logout drops the previous access result. No persistent cache
  is added.
- Update navigation/account documentation and the help corpus.

## Risks and follow-up

The bottom section intentionally has variable breathing room above its visible
actions. The desktop smoke regression covers delayed Update appearance and a
short expanded sidebar; authenticated visual behavior still needs browser
verification.

## Release notes

Search and Share remain available during account restoration. Profile loading
and account actions no longer shift those controls, and the account menu keeps
its artwork item stable during each opening.
