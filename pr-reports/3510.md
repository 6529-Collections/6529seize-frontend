# PR Report: Trust Retained Stream Solidity Snapshots

PR: [Frontend PR #3510](https://github.com/6529-Collections/6529seize-frontend/pull/3510)

Branch: `agent-prxt/fix-stream-solidity-retained-snapshot` -> `main`

Related PRs: None

## Summary

Every retained Stream Solidity snapshot now has an explicit trusted
source-commit identity, including hidden non-current drafts. Production
page-data generation can validate the complete retained index without changing
which review versions are public.

## What Changed

- Publication schema v3 records a source commit for each retained Stream
  version.
- Runtime identity construction requires the trusted identities and retained
  snapshot list to match exactly and fails closed on missing, malformed,
  duplicate, reordered, or inconsistent entries.
- Packaging enforces the same explicit trust identities before artifacts can
  be accepted. The protected snapshot verifier remains unchanged, so the
  pull-request trust check continues to execute only base-owned verifier code.
- Focused coverage protects the four-version retained set, the hidden
  `2026-07-28.1` draft, and missing or mismatched identity failures.

## Historical Root Cause

[PR #3502](https://github.com/6529-Collections/6529seize-frontend/pull/3502)
introduced a split source-index identity derived from public review definitions
plus the current source snapshot. That was valid while the only hidden draft
was also current.

[PR #3507](https://github.com/6529-Collections/6529seize-frontend/pull/3507)
then retained `2026-07-28.1` while advancing the current snapshot to
`2026-07-28.2`. The older draft was neither public nor current, so it had no
trusted runtime source-commit entry. Snapshot Trust passed, the PR merged while
App PR CI was still running, and the production build subsequently failed
during page-data collection with the source-index identity error.

## Frontend Impact

- Routes/views: Stream Solidity reference routes retain their existing public
  version projection.
- Components: Not affected.
- Generated API/client: Not affected.
- User-visible behavior: No draft is published; production generation can
  safely authenticate all retained snapshots.

## Config / Env

- `config/public-reviews/6529-stream.publication.json` is upgraded to schema v3
  and becomes the explicit retained-version source-commit trust registry.
- No environment variables are added or changed.

## Release Notes

Internal reliability fix for Stream Solidity reference generation. No public
review lifecycle or UI behavior changes.
