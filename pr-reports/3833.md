# PR Report: Prevent auth modal and network-switch collisions

PR: https://github.com/6529-Collections/6529seize-frontend/pull/3833
Branch: `agent-prxt/auth-sign-network-guard` -> `main`
Related PRs: None

## Summary

The authentication sign modal now yields to AppKit whenever a connected
wallet's active chain is unknown or unsupported, then returns automatically
after the wallet switches to a supported chain. New Coinbase Wallet
connections are also excluded from the Capacitor app while existing sessions
and web connections remain unchanged.

## What Changed

- Derived active-chain support from Wagmi's live account state and configured
  chain list.
- Applied the chain check to modal visibility without disconnecting the wallet
  or discarding the pending authentication prompt.
- Extended authentication request guards so unsupported-chain transitions stop
  nonce/sign-in work before signing or session persistence.
- Preserved non-signing session-upgrade and connection-sharing prompts when no
  live wallet is connected.
- Removed Coinbase Wallet from AppKit's new-connection choices in Capacitor.
- Partially lifted AppKit's wallet search sheet when the native keyboard opens
  in Capacitor, keeping results reachable without pushing the sheet to the top
  of the screen.

## Frontend Impact

- Routes/views: Wallet-authenticated surfaces using the shared auth provider.
- Components: Authentication provider, sign-modal orchestration, request
  guards, AppKit initialization, and the Capacitor connection chooser.
- Generated API/client: Not affected.
- User-visible behavior: AppKit's network-switch interface remains interactive;
  the authentication prompt returns automatically after a supported network is
  selected. The native app no longer offers Coinbase Wallet for new
  connections, and its wallet search sheet remains usable without covering the
  full screen when the keyboard opens.

## Config / Env

None.

## Release Notes

Fixed a wallet authentication issue where the sign request could cover the
network switch interface on unsupported chains, and removed unsupported new
Coinbase Wallet connections from the native app. Wallet search results now
remain reachable when the native keyboard opens.
