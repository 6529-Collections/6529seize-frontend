# PR Report: Video player rework

PR: [#4056](https://github.com/6529-Collections/6529seize-frontend/pull/4056)

Branch: `agent-prxt/video-player-rework` → `main`

## Summary

Make video seeking visible and usable, expose elapsed and total time, and give homepage Next Drop and Latest Drop artwork the same centered viewing area without cropping.

## What Changed

- Move the timeline above the controls, with a subtle draggable circle and a larger interaction area.
- Preserve the existing circular action buttons. A dark play/pause-and-time capsule keeps its position when paused; both the capsule and central play button resume playback.
- Keep controls visible during seeking and keyboard focus. Update time immediately while seeking, support longer durations and localized accessible values, and reset timing when the media source changes.
- Keep timeline state in a focused hook, cancel obsolete hide timers when the source empties, and preserve native seeking if pointer capture is unavailable for an ended pointer.
- Use a shared homepage frame for contained images and videos. Center submission video within its existing larger frame; retain compact feed bounds and interactive artwork behavior.
- Document the controls and update the Help Bot knowledge index.

## Frontend Impact

The shared player affects video in drops, wave submissions, and NFT artwork. Homepage changes cover both Next Drop and Latest Drop. Native-control templates, media fallbacks, and fullscreen paths remain supported. No generated API, backend, desktop, or environment configuration changes are required.

## Risks / Follow-Ups

Browser layout and interaction validation remains incomplete because the isolated fixture did not initialize. Before merging, visually check narrow players, native slider dragging, and fullscreen. The agreed mockups represent the intended design, not verified browser output.
