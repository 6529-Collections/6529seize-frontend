# PR Report: Video player rework

PR: [#4056](https://github.com/6529-Collections/6529seize-frontend/pull/4056)

Branch: `agent-prxt/video-player-rework` → `main`

## Summary

Make video seeking visible and usable, expose elapsed and total time, and keep videos uncropped while using the available artwork area on homepage and detail views.

## What Changed

- Move the timeline above the controls, with a subtle draggable circle and a larger interaction area.
- Preserve the existing circular action buttons. A dark play/pause-and-time capsule keeps its position when paused; both the capsule and central play button resume playback.
- Keep controls visible during seeking and keyboard focus. Update time immediately while seeking, support longer durations and localized accessible values, and reset timing when the media source changes.
- Keep timeline state in a focused hook, cancel obsolete hide timers when the source empties, and preserve native seeking if pointer capture is unavailable for an ended pointer.
- Use full-width homepage and detail video on mobile and desktop, with height set by the artwork aspect ratio. Decouple video size and position from loading listing, subscription, and ownership panels.
- Attach the timeline and controls to the contained video surface so they stay inside the artwork rather than extending across letterboxing, including fullscreen.
- Remove legacy height and width caps from The Memes detail video; it fills the available width without cropping. Keep compact feed bounds and reserve a mobile frame for Next Drop media that requires explicit height.
- Reserve known NFT animation dimensions before video metadata loads, and discard measured dimensions when the source changes.
- Document the controls and update the Help Bot knowledge index.

## Frontend Impact

The shared player affects video in drops, wave submissions, and NFT artwork. Homepage changes cover both Next Drop and Latest Drop. Native-control templates, media fallbacks, and fullscreen paths remain supported. No generated API, backend, desktop, or environment configuration changes are required.

## Risks / Follow-Ups

Next Drop media does not provide dimensions, so its initial placeholder can resize when metadata arrives; NFT artwork uses known animation dimensions when supplied.

Browser layout and interaction validation remains incomplete; this correction was limited to code and tests at the requester’s direction. Before merging, visually check mobile full-width sizing, desktop loading stability, control bounds, native slider dragging, and fullscreen. Component tests verify sizing mode selection and control containment, but do not establish rendered geometry. The existing staging media pack now includes unrun portrait-video geometry assertions for card 549 at mobile and desktop widths; the detail assertions also vary the parent height and insert an ownership panel to catch loading-induced resizing. These browser assertions remain unrun; homepage geometry and fullscreen still need visual verification.
