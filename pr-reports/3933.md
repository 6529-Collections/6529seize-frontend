# PR Report: Catch filesystem contract regressions before merge

The full-suite workflow failed after the WaveDropActions keyboard-focus change left its hover audit hash stale. Coverage itself remained above the floor. This PR refreshes the audited exception and makes PR CI explicitly select contracts whose inputs are read from disk, covering source scans, workflow YAML, coverage baselines, and compatibility fixtures.

The selector accounts for deletions and both sides of renames, and fails when selected tests are missing or fail. Its six-suite registry is documented in `ops/testing-strategy/file-contract-tests.md`; future filesystem contracts need explicit input registration.

The workflow now displays as **Full Jest suite and coverage**, with separate Jest and coverage outcomes. The workflow filename, triggers, coverage baseline, tolerance, and failure behavior stay intact. No application behavior changes.

## Risks / Follow-Ups

Keep the filesystem input registry current as new contracts are introduced. Existing deployment workflow fixtures use Bash's `mapfile`; local validation with older Bash remains limited and is documented in the PR.
