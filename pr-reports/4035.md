# PR Report: NFT and ReMeme video posters

PR: [#4035](https://github.com/6529-Collections/6529seize-frontend/pull/4035)
Branch: `agent-prxt/nft-video-posters` -> `main`

## Summary

NFT and ReMeme video players use existing artwork images as posters before
playback, including the homepage Latest Drop. This applies to desktop and mobile.

## What Changed

- Select poster images according to thumbnail, default, or original display mode,
  with remaining artwork fields as fallbacks when preferred fields are missing.
- Skip empty values, non-image data URLs, and known video, HTML, or model URLs.
- Retain the shared player's autoplay, playback controls, and paused-frame
  behavior. Blocked autoplay can display artwork with the play control.
- Update media documentation and the help-bot knowledge source and public index.

## Scope and Limitations

- Frontend only; no API, database, configuration, or dependency changes.
- Uses existing image URLs; no thumbnail generation for uploaded Wave/drop videos.
- Poster downloads do not have the video-source retry chain. An unavailable or
  unreachable image can still leave an empty player until a video frame loads.
- Browser/device visual verification remains outstanding, including iPhone
  Low Power Mode.

## Release Notes

NFT and ReMeme videos show available artwork previews before playback instead of
an empty video area.
