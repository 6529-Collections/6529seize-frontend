# PR Report: Desktop environment badge overlay

PR: [#4645](https://github.com/6529-Collections/6529seize-frontend/pull/4645)
Branch: `agent-prxt/desktop-env-logo-overlay` → `main`
Related PRs: None

## Summary

Desktop non-production environment badges sit centered over the existing 6529
Home logo, preserving production's logo and navigation alignment.

## What Changed

- Shared staging shows one amber `STG` badge. Local shows one compact badge with
  `LCL` above the actual browser port, or just `LCL` without a port. The port is
  read directly from the runtime URL rather than parsed from its display label.
- The extra desktop badge row is removed in both collapsed and expanded sidebars.
- The existing logo size, link area, hover treatment, keyboard focus, and sidebar
  toggle remain intact. The overlay ignores pointer events and adds no focus stop.
- Environment detection, accessible host information, other non-production
  labels, production's badge-free logo, and phone/tablet inline badges remain.
- Navigation documentation and Help Bot facts describe the placement.

## Impact

Frontend presentation only: `EnvironmentBadge` and `WebSidebarHeader`.
No backend services, API contracts, generated clients, environment configuration,
Electron code, or desktop renderer subtree changes are required.

## Release Notes

Desktop staging and local badges identify the environment without shifting the
sidebar navigation. Mobile and tablet headers keep their existing badge placement.
