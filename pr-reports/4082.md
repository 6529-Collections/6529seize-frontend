# PR Report: Fix artwork sizing

PR: [#4082](https://github.com/6529-Collections/6529seize-frontend/pull/4082)

Branch: `agent-prxt/fix-artwork-sizing` → `main`

## Summary

Fit still artwork to the available space on the homepage, Meme detail pages, and expanded Wave submissions. Preserve the complete artwork and its proportions while limiting its height to 95% of the usable screen.

## What Changed

- Desktop homepage images fit both the artwork column width and adjacent details height, subject to the screen-height cap. Mobile images use an independent frame above the details.
- Meme images replace the legacy fixed cap with a reserved frame, using metadata dimensions when available. Growing listing or ownership panels no longer vertically recenter still artwork.
- Poster-image slides use the stable image layout independently of video or HTML animation slides. Returning to HTML restores its embedded frame.
- Expanded Wave images share the video height budget, including overlay height, header, safe areas, and artwork padding.
- Portrait, square, and landscape images scale without cropping. Explicitly bounded image containers retain their existing sizing behavior.
- Browser sizing checks wait for initialized player controls before exercising layout changes and poster transitions.
- Update the media guide and Help Bot knowledge to describe the image sizing rules.

## Risks / Follow-Ups

Full-page desktop/mobile browser verification and fullscreen verification remain outstanding. Isolated CSS geometry checks do not establish the final appearance of every application state. Artwork without dimensions uses a stable fallback viewing frame, which can leave additional empty space around landscape images.
