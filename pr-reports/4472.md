# PR Report: Memes Submission Whitespace

PR: [#4472](https://github.com/6529-Collections/6529seize-frontend/pull/4472)
Branch: `agent-prxt/memes-submission-whitespace` -> `main`

## Summary

Memes artwork submissions remove surrounding whitespace from text metadata
before wallet signing, preventing valid-looking form values from being rejected
by the submission API.

## What Changed

- Trim trait values, About the Artist, and Artwork Commentary, including
  surrounding non-breaking spaces, while preserving internal spacing and
  paragraph breaks.
- Omit trait values that are empty after trimming and apply metadata length
  limits to the values that will be submitted.
- Keep form drafts and serialized payment, airdrop, allowlist, and media data
  unchanged. Existing required-field checks still reject whitespace-only text.
- Update the submission guides and Help Bot guidance.

## Release Notes

Extra spaces or blank lines before or after submission text no longer cause a
metadata whitespace error.
