# PR Report: Increase test typecheck heap

PR: https://github.com/6529-Collections/6529seize-frontend/pull/4017
Branch: `agent-prxt/ci-test-typecheck-memory` -> `main`

The Jest typecheck exhausted its default Node.js heap during a local run.
Both `typecheck:jest` and `typecheck:jest:update-baseline` in `package.json`
now pass `--max-old-space-size=6144` directly to the Node.js process running
`scripts/typecheck-test-ratchet.cjs`, allowing 6144 MiB of old-space locally
and in CI.

CI uses the package scripts through the existing `typecheck:tests` command;
the step-level `NODE_OPTIONS` override is removed. Playwright typechecking
retains its default heap limit. No application, backend, or desktop behavior
changes.
