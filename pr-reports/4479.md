# PR Report: Selected Public Wave Drop Rendering

PR: https://github.com/6529-Collections/6529seize-frontend/pull/4479
Branch: `agent-prxt/seo-selected-drop-rendering` → `main`

## Summary

Public Wave links containing `drop` or `serialNo` now include the selected post in the initial HTML instead of the latest ten posts. Older selected posts therefore have their own body content available without JavaScript.

## What Changed

- The anonymous preview includes the selected post's author, UTC publication date, full plain-text body, images, and links to other media. Storms include up to ten parts.
- Identity, Wave membership, public visibility, and moderation are checked before rendering. Private, DM, moderated, missing, and inaccessible posts produce no public preview; they do not fall back to unrelated recent posts.
- `serialNo` retains precedence over `drop`. `divider` remains an unread marker: divider-only links use the ordinary Wave feed, and adding it to a selected-post link does not change the selected content. Existing canonical generation excludes `divider`.
- The existing loading states, wallet gate, and interactive post overlay remain in place. This change uses the existing no-JavaScript preview mechanism.

## Risks / Follow-Ups

- A selected post adds one anonymous API request, with up to nine parallel additional requests for storm parts. Existing SSR deadlines apply; an inaccessible requested part suppresses the whole preview.
- Storms longer than ten parts show a notice directing readers to connect and read the remainder. Non-image media are linked rather than embedded.
- Initial HTML content is improved, but indexing is Google's decision. This change does not establish or fix the cause of the separate Meme #60 missing-canonical report; that investigation still depends on a fresh stored Google crawl.
- No backend API, database, AWS, or Search Console configuration change is required for this PR.

## Acceptance After Deployment

Open two public links to different posts in the same Wave, including one older than the latest ten. Inspect the response HTML for each selected post's text, author, date, and media; the bodies should reflect their selections. A divider-only link should retain the recent feed. Adding `divider` to a selected-post URL should leave its content and canonical unchanged. Private or unavailable selections must expose no public post content. With JavaScript enabled, the existing interactive loading and wallet behavior should remain unchanged.
