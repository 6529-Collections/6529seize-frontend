# PR Report: Separate Page Sharing and Device Connection

PR: https://github.com/6529-Collections/6529seize-frontend/pull/3663
Branch: `agent-prxt/account-share-connect-qr` -> `main`
Related PRs: None

## Summary

Separates desktop page sharing, authenticated device connection, and profile navigation into clear entry points while improving QR camera recognition.

## What Changed

- Added a supported-route desktop Share action with icon-only copy, QR, X, Farcaster, and conditional system-share controls using the exact current full URL.
- Centralized the existing native unsupported-page rules and reused them for desktop without changing native platform-share behavior.
- Moved `My Profile` and `Connect another device` into the profile-picture menu, removed the dedicated Profile rail item, and made a single avatar activation open the menu immediately.
- Limited the connection dialog to Mobile and Desktop targets, defaulting to Mobile, with no page-share controls.
- Restored a four-module QR quiet zone, explicit pure-black/pure-white colors, and crisp contained rendering while preserving connection payloads.
- Applied the supplied share-arrow treatment to desktop and native share entry points.

## Frontend Impact

- Routes/views: Share is hidden on home, Waves, Messages, Notifications, and Waves/Messages query views across desktop and native entry points.
- Components: Desktop sidebar, profile menu, page-share dialog, device-connection dialog, native header share icon, and QR rendering.
- Generated API/client: Not affected.
- User-visible behavior: Share, profile navigation, and device connection now have distinct destinations and controls.

## Release Notes

Desktop page sharing now supports copy, QR, X, Farcaster, and system sharing separately from Mobile/Desktop device connection, with improved QR scanning reliability.
