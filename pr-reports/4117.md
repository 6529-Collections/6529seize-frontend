# Inline GIF loading feedback

PR: [#4117](https://github.com/6529-Collections/6529seize-frontend/pull/4117)

GIF attachments and GIF links embedded in wave and DM messages show a centered spinner while the preview loads. The existing reserved image area remains in place; successful loading removes the spinner and failures retain the existing retry/unavailable flow.

The indicator reuses the media spinner styling, translated loading status, and reduced-motion support. It does not block image interactions. Static-image placeholders, popup controls, original-file access, and preview URLs retain their existing behavior.

This change requires only frontend deployment. It does not shorten backend conversion or download time.
