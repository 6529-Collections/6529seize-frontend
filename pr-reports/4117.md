# Inline GIF loading feedback

PR: [#4117](https://github.com/6529-Collections/6529seize-frontend/pull/4117)

GIF attachments and embedded GIF links in wave and DM messages show a bounded, left-aligned pulsing placeholder while loading. It replaces the full-container centered spinner, using the existing image skeleton colors and pulse style.

The placeholder is capped at 16rem wide and tall and fits the available space. It uses a fallback size because media dimensions are not provided in the API. The existing reserved layout remains; the loaded image keeps its normal sizing. The placeholder disappears on success, and existing retry/error handling remains.

Reduced-motion settings disable the pulse. Static-image placeholders, popup controls, original-file access, and preview URLs retain their existing behavior.

This change requires only frontend deployment. It does not shorten backend conversion or download time.
