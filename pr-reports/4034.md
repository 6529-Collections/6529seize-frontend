# PR Report: Museum rights CI isolation

PR: https://github.com/6529-Collections/6529seize-frontend/pull/4034
Branch: `agent-prxt/museum-rights-ci-isolation` → `main`
Related: [RPC portability #3911](https://github.com/6529-Collections/6529seize-frontend/pull/3911)

## Summary

Separate the Museum rights browser pack from the accumulated route-compilation workload that preceded its repeated page-readiness timeout. This is shared CI infrastructure, not an Alchemy or application change.

## What Changed

- Network IA remains the first fail-fast gate for each desktop/mobile job.
- Selected rights tests run next on a fresh server; other selected packs run on another fresh server. Each phase has its own port, compilation directory and output artifacts.
- The execution inventory accounts for gate, rights and remaining tests without overlap or omissions. Empty phases do not invoke Playwright.
- Server process groups are stopped before the next phase, including on failure and cancellation.
- A CI-only launcher builds the environment schema and starts Next on an explicit fixed port; occupied ports fail startup instead of silently moving to a different URL. Ordinary local development keeps its existing port-search behavior.
- Startup logs distinguish early server exits from readiness timeouts. Cancellation during cleanup is deferred until process-group termination finishes.
- Rights failures retain a first-attempt trace. Remote staging and production trace policy is unchanged.
- The gate keeps its 10-minute limit. Rights and remaining coverage share the existing 20-minute deadline, including their startup and cleanup. Existing assertions, one-worker execution, zero retries and fail-fast behavior are preserved.

## Risks / Follow-Ups

The original rendering timeout is not yet proven resolved. Confirm the hosted rights result and complete selected coverage; inspect the retained trace if the failure repeats. Extra cold starts consume the existing time budget rather than extending it.

The public-rendering work in [#4031](https://github.com/6529-Collections/6529seize-frontend/pull/4031) also edits the Museum worker invocation. Reconcile that overlap without importing or discarding its unrelated rendering changes. Once this infrastructure fix is validated and merged, sync #3911 with main.
