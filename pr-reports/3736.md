# PR Report: Show wallet mint allowance on home

PR: https://github.com/6529-Collections/6529seize-frontend/pull/3736
Branch: `agent-prxt/home-wallet-allocations` -> `main`
Related PRs: [Backend PR #1926](https://github.com/6529-Collections/6529seize-backend/pull/1926)

## Summary

Latest Drop and mapped Next Drop cards now show a `Your allowance` row, including
a disconnected-wallet prompt and compact allocation pills with explicit Airdrop
and Allowlist counts.

## What Changed

- Kept the allowance section visible while disconnected with a wallet-connect
  prompt, without starting an allocation request.
- Removed the redundant `Connected wallet` label.
- Rendered only nonzero Phase 0, Phase 1, Phase 2, and Public allocation parts,
  with Public restricted to Airdrop.
- Kept each pill unbroken while allowing the pill list to wrap on narrow cards.
- Distinguished loading, unpublished distribution, published-with-no-match,
  and unavailable states.
- Synced the backend OpenAPI contract and generated models.
- Updated all supported locale dictionaries, product documentation, and the
  production HelpBot index.

## Frontend Impact

- Routes/views: Home Latest Drop and mapped Next Drop mint panels.
- Components: Wallet allocation status row only; subscription awareness is
  unchanged.
- Generated API/client: Adds wallet distribution allocation models.
- User-visible behavior: The allowance row remains discoverable while
  disconnected, and connected wallets see explicit allocation types and
  quantities.
