# PR Report: Prenodes deprecation and profile statement guidance

PR: [#4290](https://github.com/6529-Collections/6529seize-frontend/pull/4290)
Branch: `agent-prxt/prenodes-profile-cleanup` → `main`
Related PR: [Backend #2170](https://github.com/6529-Collections/6529seize-backend/pull/2170)

## Summary

Profile addresses and identity statements have separate headings and actions, statement guidance stays behind its information button, and the legacy Prenodes page explains its 6529 Desktop replacement.

## What Changed

- Put the personalized Addresses heading, wallet rows and equal-width Wallet Checker/Add another wallet actions before the ID Statements section. Removed the duplicate Consolidated Addresses label and kept the wallet helper sentence naturally wrapping.
- Match the Addresses and ID Statements headings at 18px on desktop and mobile, allowing longer names to wrap naturally. Place the compact statement Add action and a slightly larger information icon beside ID Statements, retaining its 32px touch target. The tooltip preserves all four guidance points: optional statements, permanent public visibility, self-declared social accounts without 6529 ownership/post verification, and community accuracy ratings. It supports hover, keyboard focus, tap and Escape dismissal without an inline disclaimer.
- Own statement guidance visibility directly in React, including hover, keyboard focus, click/tap and dismissal. Render the popup in a body portal using the existing viewport positioning helpers; opening and closing do not depend on a tooltip library's hidden-state or animation callbacks.
- Keep guidance open when a queued scroll-into-view event arrives after activation without moving its trigger, or another area scrolls. Dismiss when subsequent page scrolling moves the trigger. Moving the pointer away does not dismiss guidance while its button retains focus; Escape and outside dismissal remain immediate.
- The Add statement flow always shows that statements are optional and fully and permanently public, including the entry forms. Scoped guidance uses 6529 branding.
- Removed Prenodes from the shared About index/contents navigation, including responsive consumers, while retaining unrelated About content.
- Preserved `/network/prenodes` as a deprecation page with an existing `/about/6529-apps` destination. Removed registry fetching, status cards and pagination.
- Updated user documentation and the published help-bot corpus, including troubleshooting, pagination and About route references.

## Frontend Impact

Profile statement display/Add views, About navigation and the Prenodes route change. Statement publication/deletion and wallet consolidation behavior remain intact. The retired hardcoded registry request was not part of the shared OpenAPI/generated model contract; those shapes are unchanged.

## Release Notes

Social accounts are self-declared; 6529 does not verify their ownership or posts. Statements remain optional and permanently public. Prenodes have been deprecated; use 6529 Desktop for TDH calculation. Saved Prenodes URLs continue to explain this replacement.

## Risks / Follow-Ups

The wallet count and backend-driven capacity remain owned by [frontend #4218](https://github.com/6529-Collections/6529seize-frontend/pull/4218); its count should align at the right of the Addresses heading when integrated. New messages use the existing English fallback for untranslated locales. The companion backend retires the registry with 410 responses while preserving every current Oracle TDH read. Publish this notice before or alongside API retirement so visitors do not see an obsolete status view.
