# PR Report: Prenodes deprecation and profile statement guidance

PR: [#4290](https://github.com/6529-Collections/6529seize-frontend/pull/4290)
Branch: `agent-prxt/prenodes-profile-cleanup` → `main`
Related PR: [Backend #2170](https://github.com/6529-Collections/6529seize-backend/pull/2170)

## Summary

Profile guidance is placed where it applies, and the legacy Prenodes page explains its 6529 Desktop replacement.

## What Changed

- Removed the generic identity-statement information icon and tooltip from Consolidated Addresses. Wallet controls and wallet-specific guidance remain intact.
- Social-account entries visibly state that accounts are self-declared and that 6529 does not connect to social accounts or verify ownership or posts.
- The Add statement flow always shows that statements are optional and fully and permanently public, including the entry forms. Scoped guidance uses 6529 branding.
- Removed Prenodes from the shared About index/contents navigation, including responsive consumers, while retaining unrelated About content.
- Preserved `/network/prenodes` as a deprecation page with an existing `/about/6529-apps` destination. Removed registry fetching, status cards and pagination.
- Updated user documentation and the published help-bot corpus, including troubleshooting, pagination and About route references.

## Frontend Impact

Profile statement display/Add views, About navigation and the Prenodes route change. Statement publication/deletion and wallet consolidation behavior remain intact. The retired hardcoded registry request was not part of the shared OpenAPI/generated model contract; those shapes are unchanged.

## Release Notes

Social accounts are self-declared; 6529 does not verify their ownership or posts. Statements remain optional and permanently public. Prenodes have been deprecated; use 6529 Desktop for TDH calculation. Saved Prenodes URLs continue to explain this replacement.

## Risks / Follow-Ups

New messages use the existing English fallback for untranslated locales. The companion backend retires the registry with 410 responses while preserving every current Oracle TDH read. Publish this notice before or alongside API retirement so visitors do not see an obsolete status view.
