# PR #4555 — Staging E2E contracts and Safe Collecting layout

The critical-shell readiness checks now select headings within `main`, avoiding the hidden legacy-browser notice while retaining the existing page-specific assertions.

The English and German TDH guide checks recognize the Explained shell and require its exact localized heading and navigation link. The previous guide contract remains required when that shell is absent, because the redesign is currently on shared staging but not main. Remove the old guide fixtures once that rollout is complete. Timeouts, retries, suite selection, and wallet behavior are unchanged.

## Acceptance

- EMMA, App Wallets, notifications, messages, and Block Finder reach their visible page headings using readiness scoped to `main`. These route checks do not assert the legacy-browser notice's visibility.
- Both TDH guide versions require their correct translated title and navigation; unknown titles, missing translations, and incorrect redesigned link destinations fail.
- Narrow-screen overflow assertions and signed-out access checks remain intact.

## Safe Collecting layout

This PR also fixes the French Safe Collecting button overflow previously reproduced on staging and production. Setup-step, main setup, and disconnected-wallet buttons constrain their width and wrap their labels while preserving the complete text and existing actions. Setup-step buttons grow beyond their 36px minimum height when needed.

The existing 2px overflow tolerance remains unchanged. French regression coverage includes both setup tabs at 375px and 320px. The layout changes were consolidated here from the superseded PR #4556.
