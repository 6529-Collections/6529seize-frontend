# PR #4424: Competition vote browser test initialization race

[Pull request](https://github.com/6529-Collections/6529seize-frontend/pull/4424)

The frozen CHAT deep-link scenario measured vote-dialog context requests before the backing leaderboard had finished its initial hydration. Its interceptor could reject that delayed background request and incorrectly attribute it to opening the dialog.

The scenario now waits for the backing leaderboard entry to attach before installing the interceptor. The strict zero-additional-request assertion and existing voting checks remain in place. Application behavior and test-pack selection are unchanged.
