# PR Report: French Safe Collecting Button Overflow

PR: [#4556](https://github.com/6529-Collections/6529seize-frontend/pull/4556)

Related PR: [#4555](https://github.com/6529-Collections/6529seize-frontend/pull/4555)

## Summary

Long French action labels on `/safe-collecting` extended outside their available width. The setup-step, main setup, and disconnected-wallet buttons now constrain their width and wrap their labels while preserving the full text and existing actions.

## What Changed

- Setup-step buttons can grow beyond their 36px minimum height when labels wrap.
- The main setup link and wallet-connect button also fit narrow screens, including 320px widths.
- Shared button defaults, translations, link targets, and wallet behavior are unchanged.
- The existing overflow assertion remains intact, with French coverage extended to both setup tabs and 320px layouts.

## Release Notes

French Safe Collecting actions remain readable and usable on narrow screens without extending the page horizontally.

## Risks / Follow-Ups

Confirm the updated layout on staging after this change is deployed. The equivalent browser layout experiment covers the French fix; it does not substitute for running the deployed E2E spec against this branch. The exploratory German 320px check still showed separate page overflow outside the fixed setup buttons.
