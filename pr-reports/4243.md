# PR Report: Meme collaborator invitations

PR: https://github.com/6529-Collections/6529seize-frontend/pull/4243
Branch: `agent-prxt/meme-collaborator-invitations` → `main`
Related PR: https://github.com/6529-Collections/6529seize-backend/pull/2162

## Summary

Artwork Traits now supports inviting multiple collaborating profiles. Invitees receive a collaboration notification and review the artwork and terms on its detail view before accepting or declining. Acceptance is final; voting starts immediately and public attribution appears only after acceptance.

## What Changed

- Add profile selection to the signed submission payload. Resubmission requires fresh invitations.
- Display private invitation statuses and cancellation for the submitter, and direct acceptance/decline for each invitee. Confirmation is tied to the exact artwork and terms version.
- Show accepted collaborator links across artwork details, leaderboards, winners, profiles and home next-mint cards, including native competition detail views.
- Preserve managed credits and accepted artwork in Drop Forge. Existing unmanaged claims keep their current editing behavior.
- Synchronize OpenAPI/generated models; update localized messages, submission/Forge documentation and help knowledge.

## Frontend Impact

The existing Notifications inbox and artwork detail views host the invitation flow. No new page is added. Profile active/won lists consume backend accepted-attribution data. Pending names remain private; the original author retains submission ownership and editing permissions.

## Release Notes

Only collaborators who accept before selection receive mint credit. Unanswered invitations close at selection. Accepted artwork and credits cannot be replaced; submit a new artwork to obtain fresh consent.

## Risks / Follow-Ups

Roll out the companion backend schema, workers and API before this frontend. Retain backend safeguards for accepted collaborations already in flight if reverting the UI. Browser E2E was not executed in this no-server, no-deployment task; state/consent and payload paths are covered at lower layers.
