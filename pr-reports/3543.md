# PR Report: Stable NFT Media Renderer Marker

PR: https://github.com/6529-Collections/6529seize-frontend/pull/3543
Branch: `agent-prxt/mint-media-renderer-marker` -> `main`
Related PRs: None

## Summary

Makes the live `/the-memes/mint` E2E media assertion independent of the latest mint's media type while preserving renderer-specific behavior.

## What Changed

- Added one `data-nft-media-renderer` contract to the actual image, video, HTML iframe, and GLB model elements.
- Updated the mint-page E2E to locate any visible supported NFT renderer through that marker.
- Added focused contract assertions for all four renderer types.

## Frontend Impact

- Routes/views: `/the-memes/mint` E2E coverage now supports every NFT media renderer used by the page.
- Components: NFT image, video, HTML, and model renderers expose a shared stable marker on their rendered media element.
- Generated API/client: Not affected.
- User-visible behavior: None; the marker is inert test metadata.

## Release Notes

Improves staging E2E durability when the live latest The Memes mint changes between image, video, HTML, and GLB media.
