# Profile sites on the 6529 chain (frontend)

[Frontend PR #5025](https://github.com/6529-Collections/6529seize-frontend/pull/5025) · [Backend PR #2544](https://github.com/6529-Collections/6529seize-backend/pull/2544) · builds on the signed records PRs #4994 and #4997 (merged)

## Summary

The site builder's side of moving profile sites to the 6529 chain. When the backend keeps profile sites on the chain, publish returns the draft with its signed publication's CID. The builder writes the next version of the person's ProfileDoc with `cms.primary.publication` and `cms.primary.package` and signs PROFILE_REPLACE: with this browser's session key when it has one (no wallet prompt), otherwise with the wallet. Rollback and unpublish do the same on 409 `cms_pointer_on_chain`; a rollback the backend refuses (422 `cms_rollback_target_refused`) is never signed. Only a draft takes the chain path. The builder waits until 6529.io serves the new site and says so, for publish, rollback and unpublish alike, if it isn't shown yet.

Nothing changes until the backend's chain flag is on.

## Frontend impact

- None while the backend flag is off.
- Once it is on: one more signature when publishing, only on browsers without a session key.
- New strings in all five locales; `openapi.yaml` and the `publication_cid` model synced from the backend.

## Deployment

Deploy before the backend's `FEATURE_PROFILE_CMS_CHAIN_POINTER` goes on (after identity switch-on, planned Wed 25 Nov 00:00 UTC, and the side-by-side check). The chain identity profile tools must register their ProfileDoc writer (`registerProfileDocWriter`) in the same release; until they do, a chain publish says this browser can't sign profile changes yet.

**Rollback:** the backend flag off; this code then never runs.

## Asks

- **The chain identity profile tools** (identity frontend PR #4992): ship their ProfileDoc writer in the same release. It carries `profile-doc-writer.ts` byte for byte as this PR does, so either can merge first. Its refusals are shown in its own words.

## Risks and follow-ups

- If 6529.io's index lags more than two minutes, the builder reports the change as submitted and not yet shown; the next page load shows it.
- **Tests:** six new suites under `__tests__/lib/profile-cms/`; all pass with `tsc` and ESLint clean on the changed files.
