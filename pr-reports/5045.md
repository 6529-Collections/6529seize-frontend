# PR Report — Surface the new 6529 Desktop app on the web

PR [#5045](https://github.com/6529-Collections/6529seize-frontend/pull/5045)

Branch `agent-prxt/desktop-web-integration` → `main`

## Summary

The new 6529 Desktop test release is discoverable on the Apps page and in site
search. The Connect Device chooser links to the installed app.

## Frontend impact

- The test-release card on `/about/6529-apps` and the Desktop result in site
  search both lead to `/desktop`.
- Staging and 6529.io offer **Connect only** and **Connect with Post Signing &
  DM Encryption**. Both open the installed app at **Accept connection** via
  `core6529://`.
- The installed app redeems codes with the production API. Accepting a
  staging-issued code fails.
- The Connect Device chooser fits full app names on one line and stacks the
  buttons on small screens.
- The 6529 Apps guide, device-connection docs, and Help Bot describe the new app.

## Risks and follow-ups

- The operating system selects the registered URL handler. Older Classic
  installs can also claim `core6529://`.
- Verify the browser-to-app handoff and production redemption on an installed
  Windows and macOS build after rollout.
