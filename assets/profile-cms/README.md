# CMS template typefaces

These unmodified variable fonts are bundled locally for the approved CMS templates. The browser does not contact a font service. Each font retains its accompanying SIL Open Font License 1.1 copyright and permission notice.

Source: [Google Fonts repository](https://github.com/google/fonts/tree/809e4d8b8d7e9364a914909bb777679606c178b8/ofl), commit `809e4d8b8d7e9364a914909bb777679606c178b8`.
