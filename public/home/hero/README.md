Cards #1, #2, #4 and #5 are resized from the existing static display files in
`public/profile-cms/templates/memes/`; their source URLs, hashes, and rights
are recorded in `lib/profile-cms/studio/meme-display-assets.json`. The shared
files are unchanged. Card #5 retains the existing first-frame still.

Card #3 is resized from the original published artwork:

- Source: https://6529.io/the-memes/3
- Original: https://arweave.net/-DN-XorrFz5cWayuzw1T3IqPpWp-KDRLOm_Aj4vTYsA
- Original SHA-256: `1e8815eb671964af7c9e5ed5cea3737666e1f5235afd11a43133df3e0ca2b778`

Encoding: Sharp 0.35.3, auto-oriented, width 720, no enlargement or cropping,
Lanczos3 resize, WebP quality 82, alpha quality 100, effort 6, smart subsampling.
720px covers the artwork's maximum displayed size at 3× pixel density. All five
files total 262,928 bytes, down from 467,280 bytes.

These assets are retained for future design exploration. The typography-only
homepage hero does not render or request them.
