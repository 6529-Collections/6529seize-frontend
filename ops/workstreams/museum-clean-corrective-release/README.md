# Network Museum clean corrective release

This workstream corrects the public Museum's collection, research, acquisition,
artist, and work presentation after the August 2026 institutional-model release.

The release is art-led and visitor-facing. It adds responsive, governed Magnum
presentation images, restores complete research manuscripts, clarifies permanent
Collection and in-process acquisition status, and removes avoidable empty or
administrative-looking states across desktop and mobile routes.

See `active-context.md` for the current handoff and `run-log.md` for exact work
and validation history.
