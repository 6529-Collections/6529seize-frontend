# Subscription minting state audit

The baseline is the current main application plus the existing visitor-copy fix in PR #4927. Screenshots use the real profile route with a local read-only synthetic API. Each state is captured as owner and visitor on desktop and mobile. The fixed date is 16 November 2026. No real top ups, transactions, settings saves, or subscription changes are performed.

## Verified findings

- The backend classifies only consecutive funded drops: 7+ Covered; 4–6 Plan a top up; 2–3 Running low; 0–1 Action required. A missing `next_unfunded` does not alter that classification. Source: backend `src/subscription-coverage/subscription-coverage-policy.ts` and forecast assembly.
- The frontend hides the explanation whenever a funded count appears. In the reported Manual, one-edition, eligibility ×1 case, 0.06529 ETH funds the selected #575, but the card says Action required in red without explaining what needs action. Reproduced with those exact safe inputs.
- Existing visitor-copy work in #4927 merged before this draft was opened. This work builds on that change and retains its mint-day artwork and title-link fixes.
- Current code hides the entire Subscriptions tab on every iOS app view and redirects direct links to Identity. That differs from the root guide’s regional US/non-US rule and from the task’s description of funding prompts alone being hidden. This task preserves the implemented purchasing gate; changing it needs a separate product decision.
- The dedicated QA wallet authenticates on staging. Its current staging profile is resolved by wallet address rather than the saved account-pool handle. The reported Zoku handle is unavailable on staging, so the exact report is reproduced using mocks. A public production GET subsequently found the same Manual, one-edition, eligibility ×1 selection of #575, but its current balance had changed to zero and the API now identified #575 as unfunded with no cutoff. That current response differs from the supplied historical one-mint-funded report; no claim is made that the old balance remains live.
