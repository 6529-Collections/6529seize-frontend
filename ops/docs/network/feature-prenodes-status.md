# Prenodes Deprecation

Parent: [Network Index](README.md)

## Overview

6529 Prenodes have been deprecated. Use the 6529 Desktop app to calculate TDH.

## Location and Entry Points

Saved links and bookmarks to `/network/prenodes` still open a page. Prenodes
is no longer listed in the About index or About contents navigation.

## What You See

- A `Prenodes` heading and a brief deprecation notice.
- `Explore 6529 Desktop` links to the existing
  [6529 Apps page](https://6529.io/about/6529-apps).
- No registration actions, status cards or pagination.

The notice is the same for signed-in and signed-out visitors. The page does
not request Prenode registry data and has no registry loading or error state.
