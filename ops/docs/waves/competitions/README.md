# Decisions in a Wave

## Overview

A wave can host several decisions while keeping one shared chat. Each
decision has its own rules, entries, voting budget and results. These pages
describe the decision experience where it is available.

Decisions were formerly called competitions. Older `/competitions` links still
open the same pages.

## Features

- [Browse and participate](feature-competitions.md): switch decisions,
  submit an entry, vote and find results without losing shared chat.
- [Create and manage](feature-manage-competitions.md): drafts, publication,
  presentation changes, result pauses and historical decisions.
