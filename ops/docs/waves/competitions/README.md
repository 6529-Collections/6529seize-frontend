# Competitions in a Wave

## Overview

A wave can host several competitions while keeping one shared chat. Each
competition has its own rules, entries, voting budget and results. These pages
describe the competition experience where it is available.

## Features

- [Browse and participate](feature-competitions.md): switch competitions,
  submit an entry, vote and find results without losing shared chat.
- [Create and manage](feature-manage-competitions.md): drafts, publication,
  presentation changes, decision pauses and historical competitions.
